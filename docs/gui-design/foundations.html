Foundations

Tokens and components shared by every screen of the operator panel.

Color

Red is the only accent. It marks what needs the operator, such as the order with the soonest signal validity, an error, or the primary action. It appears only in small marks, text, thin frames, and buttons, never as the fill of a tile or a large area. Everything else stays in ink on paper.

Structure

Screens are built from equal modules and thin rules, with square corners throughout. On the start page, frame lines run past every junction by the same 12 px, as a drafter's lines do. Every screen ends with a short note about the simulation, and the start page carries the full disclaimer.

Live updates

The orders screen, the start page, and the navigation count update themselves without a page reload. Only the changed parts are replaced. Scroll position, focus, and anything being typed stay as they are, and the time left counts down in the browser.
